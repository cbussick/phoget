# Little Tangle identity proposal

This is a separate proposal, not an application branding switch. The existing full/check-flourish family remains available in the parent directory.

- `logo-full.svg`: the approved lighter phoget noodle lettering above a tilted bowl. No visible “don't” and no check-flourish in the word. The rounded g stays clear of the bowl rim.
- `logo-mark.svg`: a noodle-check over the same tilted bowl, in the app's two blues.
- `favicon.svg`: the same compact mark in dark green ink on sky blue for small-size contrast.
- `favicon-16.png` and `favicon-32.png`: actual raster exports for browser tabs.

The full logo and favicon share the exact bowl outline and 12-degree tilt. The compact check is the existing noodle-check contour. Typography is for larger placements; it is not squeezed into the favicon.

All SVGs are self-contained vector paths with the exact app palette, no embedded raster art and no font dependencies. Accessible titles retain the canonical application name, Don't Phoget.
